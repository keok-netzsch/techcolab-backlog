Before planning, creating, modifying, testing, or documenting anything in this project,
read it completely and follow every applicable instruction as if it appeared in this file.

Also read `ARCHITECTURE.md` completely before creating or changing any script, screen,
scheduled routine, command, notification, state file, skill, configuration, or documentation.

that new work must inherit.

Do not duplicate or selectively maintain the instructions from `CLAUDE.md` here. Keeping
one canonical source prevents the documentation drift that this repository explicitly treats

automatically through this bridge.
